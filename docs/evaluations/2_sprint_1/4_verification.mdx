# Liste de vérification avant la remise

Parcourez cette liste en équipe au bloc 6, avant de poser l'étiquette.

**Le dépôt**

- [ ] `archambaultv` est toujours collaborateur du dépôt et a accès au
      projet GitHub.
- [ ] L'étiquette `alpha-v1` est posée sur `main` et publiée.

**L'application**

- [ ] Sur un clone neuf, la commande du README démarre l'application sans
      rien d'autre à installer. Quelqu'un de l'équipe l'a **réellement
      essayé** sur une machine propre.
- [ ] La base de données se crée seule et les données survivent à un
      redémarrage.
- [ ] Le README donne la commande de démarrage, l'adresse à ouvrir et la
      commande qui exécute les tests.
- [ ] Les comptes de démonstration sont chargés et documentés.
- [ ] Les parcours engagés fonctionnent de bout en bout et
      satisfont leurs critères d'acceptation.
- [ ] Ce qui est simulé est annoncé à l'écran et listé dans le README.
- [ ] La chaîne CI est verte à l'étiquette.

**Le backlog**

- [ ] Chaque récit du sprint 1 a un responsable.
- [ ] Chaque récit terminé est fermé par une demande de tirage revue, avec
      la CI verte.
- [ ] Les récits abandonnés sont de retour dans le backlog produit, avec une
      raison.
- [ ] L'état de chaque ticket est à jour.

**Les documents**

- [ ] Les documents sont à jour et complets, avec les sections du sprint 1 remplies.
- [ ] `journal.md` a une entrée par bloc, chacune commise le jour du bloc.
