# Évaluation et notation

## Comment une évaluation est construite

Chaque évaluation est découpée en quelques **objectifs**. Pour chaque objectif,
l'énoncé vous donne deux choses :

- une **description** : ce qui est attendu, expliqué en quelques paragraphes;
- des **critères** : ce que je regarde concrètement dans votre travail.

La liste de critères n'est pas exhaustive. Elle met l'accent sur ce qui est
nouveau ou central dans l'évaluation, mais ce que vous devriez déjà maîtriser
depuis les cours précédents reste attendu. Un manquement important de ce côté
peut faire baisser la note d'un objectif même s'il n'est écrit nulle part :
par exemple, des mots de passe stockés en clair dans la base de données.

Je note ensuite chaque objectif séparément avec le barème ci-dessous. La note de
l'évaluation combine ces notes selon le poids de chaque objectif, indiqué dans
l'énoncé.

## Barème

- **Avancé (100 %)** — Vous allez plus loin que ce qui était demandé. Tous les
  critères sont respectés et vos seules erreurs sont mineures.
- **Acquis (75 %)** — Vous avez atteint l'objectif. Votre travail respecte les
  critères pour l'essentiel; il reste peut-être des oublis ou des maladresses,
  mais rien qui montre une incompréhension.
- **Ça y est presque ! (50 %)** — Votre travail respecte une partie des
  critères. Vous êtes sur la bonne voie, mais l'objectif n'est pas encore
  atteint.
- **En apprentissage (25 %)** — Vous commencez tout juste à apprivoiser le
  sujet.
- **Non observé (0 %)** — Travail non remis, ou trop incomplet pour que je
  puisse juger quoi que ce soit.

:::warning[« Acquis », c'est réussi]

**« Acquis » veut dire que vous avez atteint l'objectif.** C'est la note d'un
bon travail, complet et bien fait. C'est un succès, pas un demi-succès.

**« Avancé » n'est pas la note normale.** Elle est réservée aux travaux qui vont
plus loin que ce qui est demandé. Ne soyez pas surpris si vous ne l'obtenez pas
pour tous les objectifs, ou même jamais : quelqu'un qui obtient « Acquis »
partout réussit très bien le cours.

:::

## Jugement professionnel

Malgré ce barème, je me réserve le droit d'utiliser mon jugement professionnel
pour ajuster la note d'une évaluation. Je peux tenir compte, par exemple, de la
qualité générale du travail, de l'effort fourni et de mes observations faites en classe.
