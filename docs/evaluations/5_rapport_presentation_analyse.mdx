# Présentation orale et entretien d'équipe

- **Pondération** : 17%

## Préentation orale (7 %)

Vous présentez votre projet devant la classe comme s'il s'agissait d'une
présentation devant un **nouveau** client.

## Entretien d'équipe (10 %)

Vous présentez votre projet devant le professeur uniquement commme s'il
s'agissait d'une présentation devant le propriétaire du projet (product owner),
qui a payé pour le développement du site web.
